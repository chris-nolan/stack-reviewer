Adds request rate limiting to orders-api. A token-bucket class lands first, is mounted as Express middleware keyed by client IP, then re-keyed by tenant with limits from config, and finally exposed as Prometheus metrics with a Grafana dashboard. Once all five land, every API request is limited per tenant.
